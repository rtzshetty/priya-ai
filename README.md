# Priya AI Assistant

Priya is a highly intelligent, witty, and sassy Indian female AI assistant designed to provide both functional utility and entertaining interaction. 

## Key Features

- **Personal Assistant Mode**: Handles daily tasks, provides directions, answers queries, and engages in casual, humorous banter with a unique, sassy personality.
- **Physiological Mode**: A specialized mode focused on user well-being, health tracking, and mindful interactions.
- **Bilingual Support**: Seamlessly converse in both **English** and **Hinglish** (a natural blend of Hindi and English).
- **Real-time Voice Interaction**: Supports voice dictation and text-to-speech for a truly hands-free, conversational experience.
- **Interactive Maps & Media**: Integrated with Google Maps for location services and directions, along with video generation capabilities.

## Technology Stack
- **Frontend**: React, Tailwind CSS, Framer Motion
- **AI Integration**: Google Gemini API (Text, Audio, and Video generation)
- **Backend/Storage**: Supabase
